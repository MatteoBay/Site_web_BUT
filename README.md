# Les Gardiens de l'Aube — Site d'équipe de super-héros

## Description du projet

Site web statique présentant une équipe de super-héros fictive, réalisé dans le
cadre du **TP#3 : Création d'un site avec Git & GitHub**.

Le site comporte deux pages :

- **index.html** — page d'accueil : nom de l'équipe, slogan, menu de navigation
  et présentation générale.
- **heroes.html** — présentation des trois membres de l'équipe (nom, alias et
  courte description).

La mise en forme est assurée par **style.css** (couleur de fond, couleur du
texte, police personnalisée via Google Fonts, titre mis en valeur).

## Structure du projet

```
super-heroes/
├── index.html
├── heroes.html
├── style.css
└── README.md
```

## Technologies utilisées

- HTML5
- CSS3 (variables CSS, Flexbox, CSS Grid)
- Police Google Fonts : Orbitron & Inter
- Git / GitHub

## Lancer le projet

Aucune installation nécessaire : cloner le dépôt puis ouvrir `index.html` dans
un navigateur.

```bash
git clone https://github.com/MatteoBay/Site_web_BUT
cd super-heroes
```
